# 实验室共享版：测试前功能闭环计划

日期：2026-09-18。负责人：Codex / GPT-5。状态：设计已记录，实施中。

## 1. 原始需求

本轮将个人科研工作台收口成十余位实验室成员可使用的应用，为下一轮 Agent TestLab 提供明确测试对象。不重写科研 Agent，本轮不开展大规模压测或扩建测试平台。

- 管理员创建邮箱账号＋密码登录，保留邮件验证码兼容；管理员邮箱仅存于本地配置，不写入公开文档。
- 项目、对话、任务、记忆和报告私有。现有 local 身份历史先备份再迁移到上述管理员，不修改内容。
- 公共 RAG 指登录成员共享、管理员维护，不是匿名公网公开；已有私人库不得自动公开。
- 参考 EchoMind 增加学习指导、投稿信息、金融资料研究与企业公开信息背调；优先复用基础框架和 Skill。
- coding/文件操作走受限 MCP 工作区；本轮不提供任意宿主 Shell、自动交易或远程实验执行。
- 保留现有科研功能及本机服务，下一轮形成“动机→测试→开发优化→回归→验收”的测开闭环。

## 2. 参考与职责

已阅读 EchoMind `2026.08.29改动说明.md`、使用指南/业务流程/学习文档中的 Skills 与记忆设计、加强版简历模板，并核对 AgentProfile/tool_scope 和 Skill 加载代码。它的最新扩展是角色契约＋工具范围＋路由＋提示词，不只是多段 prompt。

采用能力注册项＋方法 Skill＋受控工具＋结果/Trace 契约。普通解释/改写仍直接 Chat；需要检索的领域任务使用工具并记录来源，不能伪装成完成检索。金融仅知识解释和公开资料研究，不操作账户；企业背调不查询个人隐私。时效结论无来源时明确不足。

下载/简历/agent 中当前 PDF 用于核对目标，不当成实现证据。70份报告、意图准确率、LoRA及自动路由惩罚等未实测/未实现内容不在本轮伪造验收；小模型训练另行安排。

### 身份、记忆与数据库

PostgreSQL 延续 email 归属和原项目/会话/Run 表，增量加密码散列、禁用状态与会话版本，不重建库。Redis 存有 TTL 的登录会话、验证码/限流；认证存储异常返回503，不绕过鉴权。工作记忆缓存按用户＋会话隔离，PG消息是真实来源，缓存可重建。Markdown仍为可编辑用户偏好和项目记忆的原文；独立 Chroma 集合对项目主题记忆分块建索引，按用户＋项目过滤并语义召回，索引可由原文重建，不等同于公共论文知识库。

### 公共资料与私有产物

资料库增加 private/lab 可见性；可访问范围先验证，写入检查owner/admin。保留research_papers现有索引，托管公共库允许主Chat显式选择/自主发现。outputs下载统一核验归属；全局评测、旧本地文件导入及实验管理仅管理员开放。

### 后台任务

保留幂等、租约与事件序列，增加用户活动额度及全局队列上限。Worker有限并发；人工等待不能占完计算执行位，等待本身也有数量与时长限制。进程失联标记interrupted，不盲目重放付费步骤，不宣传任意断点续跑。

## 4. 运行约束

不清空数据库/Redis/向量库，不打印凭据，不提交环境文件；不从iCloud目录启动。重载前检查Run、Coordinator和知识库索引活动状态；实际模型流程运行时冻结前端修改。共享模式禁止免登录，校验Redis/密钥配置；本机历史归属迁移先备份。

尽量按可验证阶段commit。TLS/hook问题先定位，不禁用证书校验，不绕过秘密扫描。记录执行范围、替身、实际结果与剩余限制。
