## 2026-09-12 更新：自主研究与可组合写作

下列两条替换旧的“StateGraph 多步骤编排”条目。这里描述当前实现深度；不改写既有 RAG 实验数字，也不新增没有测量的提效比例。

- **自主科研与多 Agent 协同：** 构建自然语言驱动的科研智能体，基于需求分析动态规划并行研究子任务，自主调用论文检索、原文阅读与参考文献追踪工具；结合证据充分性审查与人工反馈进行定向补研、重规划和停止决策，形成可追溯的综述生成链路。
- **可组合 Skill 与报告交付：** 设计分阶段 Skill 发现与按需注入机制，支持 Agent 自选和用户主动指定，将内容写作指导、输出契约与 LaTeX 模板解耦；统一记录技能版本与调用轨迹，实现报告、源码及 PDF 的关联预览与项目化沉淀。

实现区别：研究视角是探索线索，不与章节固定绑定；子 Agent 按核心目标动态委派并各自选择动作。Skill 不自动授予工具权限，论文方案不等于执行了远程实验。以下旧稿保留作阶段对照。

2026-09-11：文献综述已完成指定原文、无链接文献发现及浏览器源码/PDF 交付验证。以下另列目标深度，便于后续实现规划，不把目标与当前成果混写。

项目简介：面向学术调研与技术学习，构建融合 Agent 与 RAG 的科研协作系统，支持多视角研究、人工审阅和可追溯报告交付。

- **证据驱动的科研编排：** 将检索与论文原文读取封装为工具，结合任务 Skill、多视角规划与人工反馈，依据证据缺口动态补充研究并修订报告；设置调用预算、停止条件与引用来源校验，实现文献综述生成闭环。
- **复现实验设计与科研交付：** 基于论文证据组织基线、数据、环境、指标及验收方案，区分原文事实与实验建议；通过受控 LaTeX 模板生成源码与 PDF，支持并排预览和编译日志追踪。

写法边界：不将引用 URL 集合校验写成逐条事实核验；不将实验方案生成写成自动训练或远程实验执行；不将角色分工写成已完成通用并行多 Agent 运行时。现有离线 RAG 可作为另一个条目，但应先按实际代码核对检索、重排与入库能力。未测得的性能提升比例不填写。

## 文献综述阶段可用条目

- **证据驱动的文献综述 Agent：** 基于自然语言意图识别组织多视角研究与人工反馈，调用学术检索及论文原文工具，依据证据缺口定向补研和修订；结合调用预算、引用来源校验与受控 LaTeX 编译，实现研究轨迹留存及源码/PDF 双栏交付。

## 后续目标深度

- **自主科研任务编排：** 构建结构化动作协议与 Tool/Skill 注册体系，支持 Agent 按任务需求选择技能、委派专职子任务并根据工具反馈调整计划；以作用域、预算与人工授权约束实验操作，贯通文献综合、复现设计和科研产物交付。
- **科研 Agent 评测：** 结合冻结语料、专家评分标准与工具故障注入，从引用支持、内容覆盖、方案约束及自主适应等维度开展轨迹与产物评测，通过重复运行、消融对比和 BadCase 回流驱动版本回归。
