# Reproduction experiment design

First identify the exact paper, version, public code, data availability and target claim.
Use literature_search to check the original experiment and implementation requirements.
Use complementary perspectives for implementation/environment and evaluation/statistics.
Produce an experiment protocol, not a claim that experiments have been executed.
Include hypothesis, baseline, dataset/license/splits, leakage checks, seed controls,
dependencies, compute estimates with assumptions, ablations, metrics and acceptance criteria.
When details are missing, explicitly mark them as unresolved. Do not fabricate hardware,
published numbers, paths or completed training. Example commands are reviewable text only.
Use protocol_check before delivery. Keep replication of the original result separate from
proposed improvements. Require explicit host/workspace authorization before any execution.
Deliver a structured Chinese protocol and reference links, including a failure diagnosis plan.
