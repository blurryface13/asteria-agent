# Asteria 金融 Skill 运行时适配

前面的 Anthropic 文件为原版保留，不重写其分析方法。本节仅绑定本系统实际能力。

- 按任务需要加载行业概览或模型更新，不因加载 Skill 就认为获得了新 API。
- 工具以当前 available tools 为准。未配置 FactSet、LSEG 等凭据时，不声称访问了商业数据库。
- 财务数字优先查官方财报、交易所公告或监管披露，注明报告期、币种、单位、口径、发布日期；预测与实际值分开。
- 科研 arXiv 检索不是金融资料默认入口；金融任务用已提供的公开检索及可读取的官方原文。无法读取就明确缺口，搜索摘要不等于审计证据。
- 上游 Word/PPT/Excel 是示例交付物。本运行时只承诺实际工具支持的 Markdown/PDF/图表；不能假装生成或修改了工作簿。
- 无已有模型与授权写入工具时，model-update 只生成有来源的修订建议及差异表，不声称已完成模型更新。
- 上游页数和公司数量为参考，根据用户任务确定范围，不用凑数字制造无来源数据。
- 此能力用于资料研究，不提供针对个人财务状况的投资指令，不执行交易。
