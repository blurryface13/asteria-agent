# Local adapter

The upstream excerpt is guidance, not a tool specification. Apply it to the
current read-source ledger across domains. If earliest priority cannot be
verified, qualify or remove the origin claim; the oldest collected paper is
not automatically the origin. References in papers remain unread candidates.

Researchers may use existing search/references/read tools within their assigned
goal and budget. Writers use supplied evidence only; do not pretend a separate
auditor ran. No DOCX, APA-only, neuroscience, authorship or abstract-only
assumptions apply. This skill grants no tools or execution permissions.
